# 移除模型训练页数据源展示设计

## 目标

从模型训练页面的参数卡片中移除以下展示内容：

- “数据源”分区标题；
- “服务器托管数据”展示条；
- 该展示条下方的管理员维护说明。

移除后，“训练数据集”选择器成为同一卡片中的首个配置项。

## 保留范围

- 保留训练数据集的两个选择项及其说明。
- 保留训练摘要中的数据源信息。
- 保留训练请求固定使用服务器默认数据源的现有行为。
- 不修改后台接口、训练状态、数据集参数或错误处理逻辑。

## 实现方案

直接删除 `frontend/src/pages/ModelTrainingPage.jsx` 中位于训练数据集选择器之前的数据源展示 JSX，并去掉训练数据集标题不再需要的顶部间距。

数据源请求辅助函数和训练摘要所需文案继续保留，因为它们仍服务于训练请求与摘要展示。此次不引入显示开关，也不通过 CSS 隐藏元素。

## 测试与验证

1. 先添加页面结构回归测试，断言参数卡片中不存在目标数据源展示；在当前实现下运行并确认测试因该区块仍存在而产生预期失败。
2. 删除目标 JSX 后重新运行测试，确认参数卡片不再渲染该区块。
3. 测试同时确认训练数据集选择器和训练摘要中的数据源值仍存在。
4. 运行前端构建，确认 JSX 和依赖引用均有效。
5. 在本地页面验证中确认目标区块消失，训练数据集自然上移且页面无异常留白。

## 验收标准

- 模型训练页面不再显示截图中的数据源标题、展示条和说明。
- 训练数据集选择器仍可正常使用。
- 训练摘要仍显示服务器托管数据源。
- 发起训练时仍向后台提交默认服务器数据源。
- 前端相关测试和构建通过。
